# Evidencias

Aqui se guardan capturas y salidas de comandos que demuestran el trabajo realizado.

## Criterio de nombres

`sNN-descripcion.ext`, donde `NN` es el numero de sesion. Ejemplo: `s07-panel.png`.

## Relacion con la documentacion

Cada evidencia se enlaza desde el documento que la explica, con una descripcion y el resultado observado. Una evidencia sin explicacion no cuenta como prueba.

Las capturas y salidas estan en [capturas-o-salidas](capturas-o-salidas/).
