# Memoria tecnica: laboratorio Proxmox individual

## Resumen

Resumen provisional: este proyecto construye un laboratorio individual sobre Proxmox donde se despliega y administra un servicio Linux, automatizando su configuracion con Bash y Ansible. Se completara al avanzar el curso.

## Necesidad

Disponer de un entorno reproducible y documentado para practicar virtualizacion, redes y automatizacion de la administracion de sistemas.

## Objetivos

1. Instalar un nodo Proxmox accesible por su interfaz web.
2. Desplegar al menos una maquina virtual Linux con un servicio accesible desde un cliente.
3. Automatizar la configuracion del servicio con un script Bash y un playbook de Ansible.
4. Documentar cada fase con pruebas y evidencias verificables.

## Alcance

- Incluido: nodo Proxmox, red del laboratorio, una VM de servicio, automatizacion y documentacion.
- Fuera de alcance: alta disponibilidad, clustering y servicios en produccion.
